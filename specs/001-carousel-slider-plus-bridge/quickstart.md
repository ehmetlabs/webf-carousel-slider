# Quickstart: Carousel Slider JS Bridge Parity

## Purpose

验证 JS 侧能够原样调用 `carousel_slider_plus` 的接口、参数与事件，且命名一致。

## Steps

1. 打开 `native_uis/webf_carousel_slider/example/assets/index.html` 并准备示例调用脚本。
2. 使用原始 API 命名调用方法、设置参数、绑定事件。
3. 验证调用结果与事件触发与原始语义一致。

## Expected Outcomes

- 原始 API 名称可直接使用，调用无语义变化。
- 事件名称与 payload 与原始定义一致。
- 示例脚本无需修改即可通过。
