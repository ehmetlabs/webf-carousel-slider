## 0.1.0

### Features
- ✨ Initial release of WebF Carousel Slider
- ✅ Complete Dart wrapper for carousel_slider_plus
- ✅ TypeScript definitions for type safety
- ✅ Full WebF Custom Element integration
- ✅ Support for all carousel_slider_plus features:
  - Autoplay with customizable interval
  - Infinite scroll
  - Aspect ratio and viewport customization
  - Center page enlargement
  - Vertical and horizontal orientations
- ✅ Programmatic control methods (next, previous, jumpToPage, pause, resume)
- ✅ Event-driven API with change events
- ✅ Complete documentation and examples
- ✅ React/Vue ready (via WebF CLI code generation)

### Documentation
- Added comprehensive README with usage examples
- Added Flutter/JavaScript/React/Vue examples
- Added complete API reference
- Added interactive example app

### Architecture
- Follows WebF Hybrid UI best practices
- SOLID principles compliance
- Type-safe Dart implementation
- Comprehensive TypeScript definitions
